# BLE 指令与回传数据对照表

## 发送指令格式：2 字节 ArrayBuffer `[指令码, 操作码]`

| 指令 | 发送数据 | 含义 | 设备回传 JSON | 对应 UI 变化 |
|------|:------:|------|------|------------|
| LED_ON | `A0 01` | 开灯 | `{"l":1,...}` | 灯开关=ON |
| LED_OFF | `A0 00` | 关灯 | `{"l":0,...}` | 灯开关=OFF |
| AC_ON | `A1 01` | 开空调 | `{"x":1,...}` | 空调开关=ON |
| AC_OFF | `A1 00` | 关空调 | `{"x":0,...}` | 空调开关=OFF |
| SOCKET_ON | `A2 01` | 开插座 | `{"k":1,...}` | 插座开关=ON |
| SOCKET_OFF | `A2 00` | 关插座 | `{"k":0,...}` | 插座开关=OFF |
| LOCK_ON | `A3 01` | 锁门 | `{"z":1,...}` | 门锁=锁定 |
| LOCK_OFF | `A3 00` | 解锁 | `{"z":0,...}` | 门锁=解锁 |

**超时机制**：发送后 3 秒内未收到回传 → 恢复旧状态 + Toast「设备未响应,已回滚」

---

| 指令 | 发送数据 | 含义 | 设备回传 JSON | 额外联动 |
|------|:------:|------|------|----------|
| SCENE_SLEEP | `B0 01` | 睡眠模式 | `{"m":1,...}` | 强制关灯 |
| SCENE_STUDY | `B0 02` | 学习模式 | `{"m":0,...}` | 强制开灯 |
| SCENE_REST | `B0 03` | 休息模式 | `{"m":0,...}` | 强制关灯 |

---

| 指令 | 发送数据 | 含义 | 设备回传 JSON |
|------|:------:|------|------|
| MODE_NORMAL | `B1 00` | 正常模式 | `{"m":0,...}` |
| MODE_ECO | `B1 01` | 节能模式 | `{"m":0,...}` |
| MODE_SAFE | `B1 02` | 安全模式 | `{"m":0,...}` |

---

| 指令 | 发送数据 | 含义 | 设备回传 JSON |
|------|:------:|------|------|
| QUERY_ALL | `C0 00` | 查询全部状态 | 完整 15 字段 JSON |
| QUERY_SENSOR | `C0 01` | 仅查传感器 | 完整 15 字段 JSON（预留） |

---

| 操作 | 发送数据 | 含义 | 设备回传 JSON |
|------|:------:|------|------|
| 一键全关 | `A0 00`→`A1 00`→`A2 00`→`A3 01` 依次发送 | 关灯/关空调/关插座/锁门 | 每条指令各自回传 1 次 JSON |
| 自定义文本 | ASCII 字符串（如 `hello`） | 用户自定义 | 同上格式或设备自定义回复 |

---

## 设备回传完整 JSON 格式

```json
{
  "t": 26.5,   // 温度(℃)
  "v": 220,    // 电压(V)
  "c": 0.5,    // 电流(A)
  "p": 110,    // 功率(W)
  "e": 0.123,  // 累计电量(kWh)
  "s": 0,      // 烟雾 0正常/1报警
  "d": 0,      // 门磁 0关/1开
  "h": 0,      // 人体 0无人/1有人
  "l": 1,      // 灯   0关/1开
  "k": 0,      // 插座 0关/1开
  "x": 0,      // 空调 0关/1开
  "z": 1,      // 锁   0解锁/1锁定
  "m": 0,      // 模式 0正常/1睡眠/2宿管
  "a": 0,      // 告警 0正常/1提醒/2警告/3紧急
  "u": 1       // 传感器健康 0异常/1正常
}
```

设备每次收到任意发送指令后，一律回传上述完整 15 字段 JSON。
