# 智控寝室助手 · 微信小程序

> 嵌入式互联，智能管理寝室设备

西南大学计算机与信息科学学院软件学院 —— 寝室智能化管理小程序。

## 功能概览

| 功能 | 说明 |
|---|---|
| 🔵 蓝牙连接 | 通过 BLE 与寝室设备建立连接，支持断连自动检测与重连提醒 |
| 🏠 寝室管理 | 添加/选择寝室，管理多个寝室及其设备 |
| 📡 实时监控 | 设备状态实时反馈，连接状态一目了然 |
| 🎬 场景模式 | 预设场景一键切换（如睡眠模式、学习模式等） |
| 🎮 设备控制 | 远程控制寝室灯光、插座、门锁等智能设备 |
| 👤 角色选择 | 寝室成员/管理员角色区分，权限分离 |

## 技术栈

| 层面 | 技术 |
|---|---|
| 框架 | 微信小程序原生开发 |
| 组件框架 | glass-easel |
| 蓝牙 | 微信小程序 BLE API（蓝牙低功耗） |
| 语言 | JavaScript / WXML / WXSS |
| 数据存储 | wx.Storage（本地持久化蓝牙连接上下文） |

## 本地开发

### 环境要求

- [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
- 微信小程序 AppID：`YOUR_APPID`

### 启动步骤

1. 克隆仓库
```bash
git clone https://gitee.com/yyq_20060926/smartdorm-blue-tooth-software.git
```

2. 用微信开发者工具打开项目目录 `miniprogram-1/`

3. 在开发者工具中填写 AppID 后即可预览/调试

### 蓝牙调试

- 需要**真机调试**（开发者工具不支持蓝牙 API）
- 确保手机蓝牙已开启
- 连接前需要用户授权蓝牙权限

## 蓝牙连接流程

```
用户进入首页 → 扫描附近 BLE 设备 →
选择目标设备 → 建立连接 → 保存连接上下文到本地存储 →
后续页面复用连接 → 断连自动检测 → 弹窗提醒重连
```
